# Rule facts snapshot (as of 2026-11-06)

Re-verify every run in Phase 0.

These were true when this file was written. They exist so you know what to
look for, not so you can skip Phase 0.

- Apple App Review Guidelines "Last Updated" October 16, 2026. That revision
  added rules on creative assets (no specific or discounted pricing, no
  unverifiable claims) and on hidden, dormant or undocumented features.
  June 8, 2026 clarified the spam rules for crowded categories.
- Apple uploads require Xcode 26 and the iOS 26 SDK (since 2026-04-28); the
  iOS 27 SDK is announced for April 2027. Minimum deployment target iOS 13
  (since 2026-09-09).
- Apple age ratings: new 13+, 16+, 18+ tiers (2025); social-media questions
  required on submission from September 2026; new descriptors arriving
  2026-11-16, answers required from all apps by 2027-01-12.
- Google Play: new apps and updates must target API 36 (since 2026-08-31).
  New personal accounts: closed test with 12 testers opted in for 14
  continuous days before production.
- Apple's own figures for 2025: about 9.1 million submissions reviewed and
  about 2.1 million rejected. Apple says over 40% of unresolved issues relate
  to guideline 2.1 (completeness).
